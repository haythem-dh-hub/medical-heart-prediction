# Plan de projet

## Titre

Analyse de donnees medicales pour la prediction des maladies cardiovasculaires a l'aide d'Apache Spark et des reseaux de neurones profonds

## Problematique

Les maladies cardiovasculaires constituent une cause importante de mortalite. L'exploitation des donnees medicales permet d'identifier plus rapidement les patients a risque. Ce projet vise a comparer plusieurs approches de prediction, notamment le machine learning classique, Apache Spark pour le traitement evolutif des donnees, et un reseau de neurones profond pour la classification.

## Objectifs

- Analyser un jeu de donnees medicales sur les maladies cardiaques
- Preparer les donnees pour plusieurs approches de modelisation
- Construire un modele classique de reference
- Construire un modele base sur un reseau de neurones profond
- Utiliser Apache Spark MLlib pour un scenario de donnees massives
- Comparer les performances des approches
- Proposer une interface simple de demonstration

## Outils

- Python
- Pandas
- Scikit-learn
- TensorFlow / Keras
- Apache Spark / PySpark
- Streamlit
- Matplotlib
- Seaborn

## Methodologie

1. Collecte du jeu de donnees
2. Nettoyage et pretraitement des donnees
3. Analyse exploratoire
4. Entrainement d'un modele classique
5. Entrainement d'un reseau de neurones profond
6. Entrainement d'un modele distribue avec Spark MLlib
7. Evaluation et comparaison
8. Demonstration avec interface utilisateur

## Resultats attendus

- Un modele classique de base
- Un modele deep learning pour la prediction
- Une experimentation avec Apache Spark
- Une interface simple pour saisir les donnees d'un patient
- Un rapport expliquant les etapes, les choix techniques et la comparaison des resultats

## Valeur du projet

Le projet montre une progression claire:

- approche simple avec scikit-learn
- approche avancee avec reseau de neurones profond
- approche scalable avec Apache Spark

Cette structure est adaptee a un projet de fin d'etudes car elle combine theorie, pratique et comparaison experimentale.
